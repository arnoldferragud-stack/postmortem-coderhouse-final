# PostMortem-Coderhouse

## Descripción

Este repositorio contiene la actividad final del curso de Coderhouse sobre documentación técnica, análisis post-mortem y control de versiones utilizando GitHub.

## Objetivos

- Documentar un incidente técnico.
- Aplicar un análisis Post-Mortem constructivo.
- Utilizar control de versiones mediante GitHub.
- Publicar la documentación con GitHub Pages.
- Reflexionar sobre el uso del feedback radicalmente sincero.

## Tecnologías utilizadas

- GitHub
- GitHub Pages
- Markdown
- Notion
