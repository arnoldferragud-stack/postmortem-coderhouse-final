Cuando un despliegue falló

Análisis Post-Mortem de un incidente técnico

Contexto

TaskFlow es una aplicación web creada para gestionar tareas dentro de pequeñas empresas. El proyecto fue publicado mediante GitHub Pages para realizar pruebas con usuarios antes del lanzamiento oficial.

Problema

Después del despliegue el sitio únicamente mostraba una pantalla completamente blanca. Los usuarios no podían acceder a ninguna funcionalidad.

Acciones realizadas

  • Se revisó el despliegue.
  • Se inspeccionó la consola del navegador.
  • Se detectó un error en el nombre de un archivo JavaScript.
  • Se corrigió el problema.
  • Se realizó un nuevo despliegue.

Post-Mortem

Causa raíz: El archivo App.js tenía un nombre distinto al referenciado desde el HTML. GitHub Pages diferencia mayúsculas y minúsculas.

Aprendizajes

Este incidente permitió comprender la importancia del control de versiones, la documentación técnica y la revisión colaborativa antes de cada despliegue.

Feedback Radicalmente Sincero

El feedback recibido permitió simplificar la documentación para que pudiera ser comprendida tanto por perfiles técnicos como no técnicos.
